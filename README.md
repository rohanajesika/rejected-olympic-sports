A program that writes one funny line — a rejected Olympic sport, "Synchronized Apologizing: two Canadians say sorry in perfect unison — until one of them actually means it." — to `/output/entry.txt`. One sentence, 106 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Rejected Olympic Sports" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
